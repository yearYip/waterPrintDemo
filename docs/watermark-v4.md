# 4.0：角点定位水印

5.1.3 沿用本页的普通水印载体与定位流程，使用 WMK3 紧凑编码并兼容 WMK2。有纹理区域的导频上限调整及版本变化见 [watermark-v5.md](watermark-v5.md)。当前 5.2.0 的算法见 [DWT-DCT-SVD 水印试验版](watermark-dwt-dct-svd.md)。

下文记录 4.0 的 WMK2 设计；5.1 新生成图片使用 WMK3。旧版 WMK1 图片不会被新版解析器识别。

## 生成

- 图片按短边至少 320 像素的规则沿宽、高自适应分块，每轴最多 6 块。宽和高均至少 1920 像素时可达到 6×6。只能分成一块的小图也使用相同生成流程。
- 每块都写入完整的用户 ID、设备 ID、时间戳和 CRC32。先尝试频域水印；无合适频域载体时保留 PNG 原图水印。
- 每块四角附近写入四种不同的低亮度变化色度信号，用于自动定位区域边界；角点信号本身不携带用户信息。最后写入 PNG 水印。4.0 曾在生成时检查回读；当前版本已移除生成时回读。
- 短边低于 64 像素，或分块不足以容纳完整消息的图片会报告生成失败。单块短边低于 320 像素时，频域水印可能无法写入，只保证保存的 PNG 原图回读。

## 解析

1. 优先从完整 PNG 或首块直接读取 WMK2 消息。
2. 对需要定位的截图或局部图片，将最长边缩至不超过 800 像素，扫描固定的一组角点信号尺寸。此过程无需本机保存原图或缩略图。
3. 将四种角点组成候选区域，按分数优先解码。找到有效的 WMK2 消息及 CRC32 后立即返回；失败时再微调高分候选区域。
4. 用户仍可手动选取一个完整区域的四角。找不到能组成完整区域的四个角点时，会提示并结束解析，不继续尝试水印解码。

生成和解析结束后，界面会显示对应的实际用时。当前生成用时包含图片读取与水印写入；相册保存发生在生成计时之后。解析用时包含图片读取、角点搜索及水印校验。

图片必须保留足够的角点信号以及完整水印区域。严重缩放、压缩、拍屏失焦或裁掉所有完整区域时仍可能无法自动恢复。低色度纹理或接近纯色的图片也可能使角点较难识别。

本版按用户要求未运行 Android 构建或设备测试；解析速度和截图成功率需要在 Android Studio 和目标设备上验证。
