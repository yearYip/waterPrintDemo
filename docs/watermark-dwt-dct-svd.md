# 5.3.0–5.5.0：DWT-DCT-SVD 水印试验记录

此文件记录旧版载体；当前版本见 [5.6.1 DCT 水印](watermark-dct.md)。

5.2.0 按独立区域归一化到 512×512，使用亮度通道、Haar DWT、4×4 DCT、最大奇异值量化，并用角点和导频寻找完整区域。5.3.0–5.4.0 转向整图 DWT-DCT-SVD。5.5.0 使用 YUV 三通道、Haar DWT、4×4 低频块 DCT 和双奇异值量化（36、20）；固定 512 位 WMK3 消息在 16 行 × 32 列网格中二维重复。读图时搜索分块相位、消息起点及部分缩放比例，凭 CRC32 确认结果。

5.5.0 的模拟器测试覆盖整图 PNG、JPEG 90、无水印拒绝、完整截图手动选四角、整图缩至 75% 与 50%、4 个不同起点的 320×256 局部 PNG、320×256 局部 JPEG 90、局部区域再缩至 50%。这些是模拟样本，不代表真实软件压缩或所有照片的回读率。
