# 5.2.0：DWT-DCT-SVD 水印试验版

本版参考 [blind_watermark](https://github.com/guofei9987/blind_watermark) 的 DWT-DCT-SVD 思路实现 Android 本地载荷。实现使用项目自己的 Kotlin 数学代码，没有引入 Python/OpenCV 依赖，也不与该仓库的图片格式互通。

生成时仍按原界面填写用户 ID，并自动加入设备 ID 与时间戳。每个独立区域都写入完整消息。区域图像归一化到 512×512 后，对亮度做 Haar DWT，在低频的 4×4 块上计算 DCT 和最大奇异值；密钥固定在代码中，控制块与 DCT 系数置乱。量化最大奇异值写入导频或纠错数据位。消息仍使用 WMK3 长度字段、卷积纠错和 CRC32，因此实际消息长度可变，解析时无需输入长度。角点标记继续用于从截图中寻找完整区域。

本版生成、解析均不再调用旧的 DCT/QIM 载荷和 PNG LSB 路径；以前生成的图片不能由当前解析流程保证读取。保存格式仍为 PNG。生成完成不再自动回读，界面显示写入区域数及耗时。

验证记录：Debug APK 和 JVM 单元测试构建通过；Android 模拟器上，320 与 512 像素区域的 PNG 回读、完整区域裁剪后 JPEG 质量 85 回读、整图缩至 80% 后 JPEG 质量 85 的自动定位回读通过。该结果只覆盖合成纹理图，不代表微信等软件的实际压缩、任意局部截图、严重透视变化或所有照片都能成功。请用实际生成 PNG 和目标软件处理后的文件分别测试。

密钥写死在 App 中，只用于生成与解析一致的置乱；它不能阻止逆向提取，也不直接提高抗压缩能力。
